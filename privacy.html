Kebijakan Privasi

Berlaku sejak 17 November 2026

ytauto ("aplikasi") adalah alat pribadi milik pemilik channel YouTube Haswell Tech. Kebijakan ini menjelaskan data apa yang diakses aplikasi dan bagaimana data itu digunakan.

Layanan API YouTube

Aplikasi ini menggunakan Layanan API YouTube. Dengan menggunakan aplikasi ini, Anda tunduk pada Ketentuan Layanan YouTube dan Kebijakan Privasi Google.

Data yang diakses

  • Izin youtube.upload dan youtube pada akun YouTube milik pemilik channel, hanya untuk mengunggah video, mengatur metadata (judul, deskripsi, tag, status privasi, jadwal tayang), dan menambahkan video ke playlist milik channel tersebut.
  • Informasi dasar channel (nama dan ID channel) untuk memastikan video diunggah ke channel yang benar.

Penggunaan dan penyimpanan

  • Token akses OAuth disimpan secara lokal di server milik pemilik channel dengan izin akses terbatas, dan tidak dibagikan ke pihak mana pun.
  • Aplikasi tidak mengumpulkan, menjual, atau membagikan data pengguna lain. Aplikasi tidak menggunakan cookie atau pelacakan.
  • Data diproses hanya untuk tujuan di atas.

Mencabut akses

Akses dapat dicabut kapan saja melalui halaman izin akun Google. Setelah dicabut, token yang tersimpan menjadi tidak berlaku dan dapat dihapus dari server.

English summary

This app uses YouTube API Services; by using it you agree to the YouTube Terms of Service and the Google Privacy Policy. It only accesses the channel owner's own YouTube account to upload videos and manage their metadata and playlists. OAuth tokens are stored locally on the owner's server and are never shared. No other user data is collected. Access can be revoked at any time at Google account permissions.

Kontak: melalui channel YouTube Haswell Tech atau GitHub Issues.
